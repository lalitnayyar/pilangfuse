# LinkedIn short post

Most AI demos stop at the prompt.

Buyers want more than that.
They want workflows that are:
- useful
- observable
- repeatable
- easy to operate

That is why I built **pilangfuse**.

It is a **Langfuse-traced multi-agent research workflow** that turns one topic into:
- curated web research
- relevant YouTube references
- a polished markdown brief
- live activity updates
- traceable execution for debugging and trust

What I like most is that it is not just an AI backend.
It is a usable product experience with:
- browser UI
- API access
- retry/fallback logic
- in-app settings
- Docker-ready deployment
